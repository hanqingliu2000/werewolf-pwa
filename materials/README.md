## 使用条件

- 先根据 [新版素材要求](../docs/05-narration-and-assets.md) 审查文案、公开或私密语境及对应规则。
- 不能直接把旧 JSON 中的角色提示、错误措辞或敏感词列表作为新的隐私机制。
- `hunter_reaction_open.mp3` 需要核对猎人身份的公开时点；网络提示只供公共主持设备在合适语境下使用。
- 音频只用于公开旁白，私人查验、女巫刀口及队友协作不播报。
- 旧素材的来源授权与新产品音质验收均待补充，不默认标记为正式发布可用。
- 正式素材需确定版本与记录；未选择的试音不得与主音频混播。

旧生成脚本、生成环境细节、SVG 图标源和 Android 默认启动素材可在 `archive/pre-rewrite-2026-10-06` 中查阅。本目录只保留可比较的原始候选材料。
