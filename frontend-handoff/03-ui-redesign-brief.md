# 03. UI 改版 Brief（给前端生成 AI）

## 目标
在不改变玩法机制的前提下，输出“现代、简洁、美观、桌游/狼人杀主题”的前端界面。

## 风格方向
- 关键词：`Dark tabletop` `Moonlight` `Clean cards` `High contrast`
- 配色建议：
  - 背景：`#0B1020` / `#121A2B`
  - 主色：`#7C8CFF`（行动）
  - 强调：`#F2B544`（警示/结算）
  - 成功：`#34D399`
  - 危险：`#F87171`
  - 文本：`#E5E7EB` / 次级 `#94A3B8`

## 页面改版重点
1. **/create（建房）**
   - 将规则配置分为「基础」「进阶」两层；进阶默认折叠。
   - 对危险配置（如女巫双药同夜）加说明 tooltip。

2. **/join（入房）**
   - 大号房间码输入框 + 自动大写 + 6位校验。
   - 清晰错误反馈（房间不存在、昵称重复等）。

3. **/room/[roomId]/lobby（大厅）**
   - 左右分栏：玩家列表 / 规则摘要。
   - 房主操作区固定在底部（Start 按钮强强调）。

4. **/room/[roomId]/play（对局）**
   - 顶部“阶段进度条”（夜晚流程可视化）。
   - 中部“当前行动区”（只呈现本角色可做操作）。
   - 底部“系统事件流”（最近事件卡片）。
   - 对“死亡玩家”显示明显但克制的禁用态。

5. **移动端优先**
   - 主按钮高度 >= 44px，避免误触。
   - 关键操作采用二次确认弹层（尤其狼人确认、猎人开枪）。

## 动效规范
- 只做轻量动效（150~220ms，ease-out）。
- 禁止炫技级动画，避免影响夜晚快速操作。

## 可访问性
- 文本对比度符合 WCAG AA。
- 操作按钮有清晰 focus 态。
- 颜色不是唯一信息来源（配 icon/文案）。
