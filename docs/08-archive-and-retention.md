## 查看和恢复旧实现

在仓库根目录查看旧产品简述：

```sh
git show archive/pre-rewrite-2026-10-06:01-brief.md
```

需要独立查看整个旧版本时，创建旁边的独立工作树，避免覆盖新基线：

```sh
git worktree add --detach ../werewolf-pwa-legacy-review archive/pre-rewrite-2026-10-06
```

也可以导出旧版本的已跟踪文件：

```sh
git archive --format=tar --output=../werewolf-pwa-legacy-2026-10-06.tar archive/pre-rewrite-2026-10-06
```

以上恢复命令是供以后选择使用的说明，本轮没有运行。Git 导出不包含私人环境配置、依赖、云端数据或原先被忽略的生成文件。
