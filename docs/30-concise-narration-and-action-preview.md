# 精简播报与提前预选

2026-10-12。本地实现狼人必须选择击杀目标、预言家必须查验他人；精简每种角色的语音，并在睁眼段实际播放结束后弹出私密操作框。尚未提升正式部署，当前正式站仍为e0709f3。

## 行动与计时

- 狼人不再提供空刀，必须选择存活玩家，可以自刀或选择队友。最多票决定、最高票并列随机、本人改票撤销本人确认的规则不变。
- 预言家不再提供放弃查验，必须选择其他存活玩家，可重复查验，只获得阵营。
- 守卫不守、女巫不用药、猎人放弃仍保留。历史记录中的旧空刀和旧放弃动作保持可读取，不改写已接受结果；不能通过新请求再提交这些已取消的动作。
- 本轮默认采用此前计时约定：先弹框允许预选，完整播报结束后才允许提交并开始10/30秒。预选不消耗药剂、不产生查验、不提交狼人提议。
- 睁眼和行动说明拆成两段，用真实AudioBufferSource ended触发，不猜测音频已经播完。睁眼段结束后房主发出当前公开cue的action_prompt通知，并有半秒过渡；其他前台页面通过公开同步和本人资格检查展示面板。网络同步仍有延迟，不宣称所有设备在同一毫秒打开。
- 开眼说明期间和正式行动窗口共用同一面板，目标草案不丢失。提前关闭后不自动重开；后台、真正暂停或不同回合仍遮蔽、清理私密信息。公开播报和倒计时不跟随私密选择变化。

## 服务与隐私

新增仅房主可调用的action_prompt，核对成员、当前窗口、公开cue、音频版本、前台声音心跳及非暂停状态；只标记预选资格，不开始计时。重复请求返回原回执，旧cue或非房主请求被拒绝。完整cue_ack或announcement_done仍是计时入口。

公开narration.promptedCueId只表示已播完当前角色的公开开始段，不包含谁还活着、谁打开了界面或谁已行动。本人响应在合法时增加previewAction，死亡、无药神职与其他玩家没有对应预选权限。女巫有解药时可在合法预选中看到本夜刀口，但必须等正式窗口才能提交。所有配置过的死亡角色仍完整播放开始、行动说明与闭眼片段，保留同长窗口。

数据仍由唯一TypeScript核心解释，保存适配未增加SQL规则或数据库结构。狼人和预言家的非法空目标由核心拒绝，预选阶段直接发送动作也会被拒绝，不依赖按钮禁用保护。
