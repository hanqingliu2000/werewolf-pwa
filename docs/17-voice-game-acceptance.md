# 17 多人语音对局验收

验收日期：2026-10-07。当前音频为 `host-zh-v2`，规则为 `werewolf-web-v1`。用户确认现有素材试听听感可接受，本轮补充完整多人语音网页流程和故障恢复验收；未部署或改动云端数据。

## 模拟方式

使用 Playwright 的手机尺寸浏览器，每名玩家独立 BrowserContext、Cookie、页面和私密视角。Chromium 以可见窗口完成8人、12人模拟，不使用原生安卓模拟器。房主同时参与游戏，只有房主页面播放公开音频。

测试玩家执行确定性脚本，不是独立 LLM 策略代理。测试编排通过各自会话的私密接口读取身份以选择覆盖场景，产品房主视角仍不读取其他人的身份。这不代表阶段7的线上独立玩家仿真已经完成。

真实加载、校验、解码和播放 MP3，不替换音频、加速音频或伪造 ended 回调。仅在隔离的 `web/test-results/browser.sqlite` 中压缩已经提交行动后的等待窗口和对应限流时间，不修改生产计时规则、角色分配或实际对局数据。

## 验收发现与修复

1. 首次8人验收离开对局查看复盘后直接重开，新大厅公告等待重新解锁音频。这符合离开页面后不自动恢复的约束。验收现明确返回后先重新试音确认，再重开，不用伪造回执消除等待。
2. WebKit 真正刷新时，旧页面未完成的前台心跳曾产生访问检查错误。普通前台心跳现在具有 AbortSignal，在 pagehide、隐藏及卸载时取消；被取消或失败的心跳不再启动后续刷新。离线 Beacon、后台不可用通知和已提交的游戏命令保持原有语义，不取消游戏提交，不撤销服务器已接受的操作。
3. 新的取消回归只挂起普通 fetch 心跳，先确定性触发 pagehide 检查取消信号，再真正刷新。首次夹具误拦 Beacon 和依赖卸载日志写入的问题已修正；没有过滤 pageerror。真正音频中断和刷新另由原有恢复用例验证。
