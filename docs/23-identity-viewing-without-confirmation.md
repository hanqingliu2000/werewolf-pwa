# 23 取消身份确认

更新：2026-10-08。取消发牌后的逐人身份确认，保留可选私密查看与房主开始首夜。已完成本机验证；本次不提升正式部署，此前正式 V2 整局验收仍见 [22](22-production-voice-game-acceptance.md)。

随后用户授权正式更新，发布及线上短程验收见 [24](24-identity-flow-production-release.md)。以下保留本机开发时的验收范围。

## 新流程

- 大厅满员且全员准备后发牌，大厅准备要求不变。
- 玩家默认看到统一牌背，可以查看本人角色与能力，再收起；不显示“确认身份”按钮或确认状态，不跟踪查看进度。
- 发牌播报结束且主持可用后，房主可直接“开始首夜”，不等待任何玩家查看或确认身份。
- 刷新、后台与失联仍走既有安全暂停和显式恢复；开始首夜不自动开放行动计时，开眼播报实际结束后才计时。
- 狼人共同确认、角色行动确认、白天结果核对、猎人反应、隐私遮蔽和前台自动行动窗口保持不变。

内部 `reveal` 仍表示私密发牌，不再是身份确认阶段。新局不保存 `roleAcknowledgements`；旧快照中的此字段不影响推进，不需要数据库迁移。为保持 `/api/v2` 结构，旧 `acknowledge` 命令仅在合法发牌上下文接受为无效果兼容请求；本人响应中的 `acknowledged` 只表示已发牌，当前网页不使用它。成员、房主、局、窗口和重复请求校验不变。

## 发牌音频

当前分支采用 `host-zh-v3`，新台词为“身份已经发放。请查看本人的身份，然后收起私密信息。”。沿用已选的 Uncle_Fu 平直播报声线、固定模型 revision、生成参数和响度目标；不要求点击确认。

仅在本机重生成发牌片段，其余39段与 V2 字节相同并沿用匹配指纹的复核结果。V2 文件未覆盖。新片段8.88秒、107,468字节，SHA-256为 `67b3013b3f5951928cb166beb024cd498973c27d8fa0496a21487c14f5d62bf4`；本地转写完整对应台词，解码峰值约-1.87dB。整套40段共164.48秒、2,013,728字节。

语音版本保护仍有效：已有 V2 语音房间升级后暂停并保留行动、剩余时间与公告，房主重新试音并明确恢复，或明确改用文字。旧版本的完成回调不能推进新阶段。试听页为 `/audio/host-zh-v3/index.html`，默认不发声。模型缓存、原始WAV与复核报告保留在忽略的本机目录，不提交。
