# 02 规则与决策

更新：2026-10-06。状态：首版关键规则已确认，配比与现场体验待实测。

本文件记录用户已选规则与已制定的实施默认值。规则选择不等于已经验证板子平衡，旧代码行为不作为规则答案。实现和验收顺序见 [09](09-phased-development-plan.md)。

## 基线原则

- 每局固定人数、角色配比、规则版本与公开信息政策，游戏中不悄悄修改。
- 发牌随机；角色总数与实际人数一致；不默默截断或补足错误配置。
- 预言家查验默认只表达阵营，不能额外返回具体职业。
- 常规夜晚动作只允许存活的合法角色提交。猎人死亡反应是明确、一次性的例外。
- 同一批死亡先完整结算，再完成合法死亡反应，最后判胜，不能用中间态决定赢家。
- 非支持的角色重复或规则组合在开局前拒绝，不在游戏中临时降级。

## 六角色范围

| 角色 | 能力 | 必须明确的边界 |
| --- | --- | --- |
| 狼人 | 共同选择夜晚击杀目标 | 队友可见性、共同确认、空刀、自刀、分歧与超时 |
| 预言家 | 每夜查验一个合法目标的阵营 | 是否允许重复查验；提交后如何保留私密记录 |
| 女巫 | 在次数范围内选择救、毒或放弃 | 自救、同夜双药、解药目标、刀口可见性、资源消耗时点 |
| 守卫 | 每夜守护一个合法目标 | 是否自守、连守、空守，以及与解药叠加的效果 |
| 猎人 | 符合死因规则时开枪或放弃 | 夜晚和白天出局、被毒、复合死因、反应顺序 |
| 平民 | 参与白天讨论和投票 | 夜晚无真实行动，不显示会暴露他人身份的等待信息 |

| 女巫同夜用药 | 同一夜最多使用一瓶药，也可以不使用 | 本轮已明确；不允许双药 |
| 女巫救人 | 解药仅用于本夜合法刀口；空刀时不能使用解药 | 已确认 |
| 毒药与防护 | 守护和解药都不挡毒；女巫本夜被刀未获救仍可用毒 | 已确认；统一结算夜晚死亡 |
| 女巫刀口可见性 | 本夜女巫行动窗口开始时仍有解药，才可获知本夜狼刀目标；解药用掉后的夜晚不再提供新刀口 | 本轮已明确；刀口不是最终死亡名单 |
| 猎人反应 | 被狼人击杀或白天投票出局可开枪；本次出局只要受到毒药作用，无论是否同时符合其他可开枪死因，都不能开枪 | 本轮已明确；毒药禁枪优先，包含同夜狼刀加毒药 |
| 猎人公开与放弃 | 出局时公开猎人身份；有资格时本人选择开枪或放弃；被毒或放弃仍公开身份，反应结束后不可补枪 | 已确认；夜晚在天亮出局公告时公开，白天在发布淘汰时公开 |
| 普通出局翻牌 | 其他角色出局不自动公开身份，不直接公布死因 | 已确认；猎人身份是明确例外 |
| 狼人目标 | 可自刀、刀队友或共同空刀；每个存活狼人一致确认后锁定 | 已确认；提议变更清除旧共同确认 |
| 预言家目标 | 不验自己，可重复查验或放弃；确认后只得知阵营 | 已确认 |
| 毒药与猎枪目标 | 毒药可选本局任一存活玩家，包括自己；猎枪只能射其他存活玩家 | 已确认 |
| 行动锁定 | 选择是可更改草案，正式确认后锁定；狼人以最终共同确认为锁定点 | 已确认；不允许各自锁定矛盾目标导致无法协商 |
| 超时 | 未完成时暂停，不代选、不自动放弃；房主恢复窗口延长 30 秒 | 已确认；普通窗口 30 秒，狼人 45 秒 |
| 白天更正 | 选择、确认待发布、再发布；发布前可改，发布后不可撤销 | 已确认；严重误录可明确中止重开 |
| 局后信息 | 本局参与者可见全部身份与逐夜行动 | 已确认；后来加入者不能看此前未参与的复盘 |

两种狼人胜利方式是独立的开局选项，不叠加。选择屠边时，狼人和好人人数相等本身不判胜；“人数规则”也不等于“杀光全部好人”的屠城规则。不能只用“A/B”向玩家描述胜负。

神职为预言家、女巫、守卫和猎人；药剂耗尽不会把女巫变成平民。配置必须同时包含狼人、平民和神职，避免开局误判屠边。先结算整个死亡批次并完成合法猎人反应，再依次检查全员出局平局、狼人全灭好人胜、所选狼人胜条件；不采用狼刀在先。最后神职是猎人时仍可合法反杀。

## 已选规则的边界与例子

- 女巫自救仅限本局第一夜，不是“自己第一次被刀的夜晚”。第二夜起即使还有解药，也不能救自己。
- 女巫看到的是狼人选择的击杀目标，不是最终死亡玩家；目标可能被守护或被解药救下。公开死亡名单仍在黎明按公告政策发布。
- 守卫守 A、下一夜空守、再下一夜守 A 合法；连续两夜守 A 不合法。空守不是守护某人，可以连续选择空守。
- 同守同救不会使狼刀重新生效；守护和解药均不能抵挡毒药。
- 猎人仅被狼刀击杀或被白天投票出局时有开枪资格；仅被毒、同夜被刀且被毒，都没有开枪资格。不能只保留一个“主要死因”而丢掉毒药造成的禁枪效果。
- 普通出局公告只公开座位和出局状态，不自动展示职业或死因。猎人出局时公开身份，即使不能或选择不开枪也不隐藏；内部夜晚结算不得早于天亮公告公开身份。

## 与常见玩法的区别

本项目不宣称采用唯一标准规则。公开规则中女巫自救存在全程禁止、仅首夜允许和全程允许等变体；本轮选择仅首夜允许。参见 [女巫自救规则](https://www.langrensha.net/strategy/2022121302.html)。

守救不冲突是需要开局显著说明的区别：常见国内规则有“同守同救导致拯救失败”的设定，本项目明确不采用。参见 [守卫规则详解](https://www.langrensha.net/strategy/2022062701.html)。这是降低反直觉情况的产品取舍，其对胜率的影响需要实测。

屠边和同刀同毒不能开枪都有公开规则先例，分别参见 [屠边说明](https://www.langrensha.net/strategy/2022022201.html) 和 [猎人同刀同毒说明](https://www.langrensha.net/strategy/2022050601.html)。这些参考不代替本项目对结算顺序和信息公开的明确约定。

## 已选决策与验证重点

| 编号 | 已选决定 | 验证重点 |
| --- | --- | --- |
| D01 | 8 至 12 人、六角色、屠边默认和人数规则可选 | 配置检查；候选配比不宣称已证明平衡 |
| D02 | 自守、空守、禁止连守、守救不冲突、防护不挡毒 | 全部相关目标组合的结果一致 |
| D03 | 各一瓶药、仅首夜自救、无双药、有解药看刀口、被刀仍可用毒 | 资源消耗一次；无解药或空刀不错误提供救人动作 |
| D04 | 完整结算与合法反应后判胜，全员出局平局，受毒优先禁枪 | 同刀同毒、最后神职反杀和同批双方全灭 |
| D05 | 狼人全体一致；超时暂停；30 秒与 45 秒窗口，恢复加 30 秒 | 提前完成不提前闭窗，不代选、不自动放弃 |
| D06 | 普通角色不翻牌，猎人出局公开身份；遗言在线下处理 | 猎人中毒或放弃仍公开，但不早于出局公告 |
| D07 | 白天结果待发布可改，发布后不可撤销；可明确中止重开 | 不回收已公开的身份、不伪造中止局胜负 |
| D08 | 局后公开身份与逐夜行动，实施默认保留 24 小时 | 限本局参与者可见；到期和新局隔离 |
| D09 | 仅原浏览器恢复；房主手机主持；无接管或额外公共设备 | 房主出局有组织权限，失联等待原设备 |
| D10 | 合法目标和确认锁定按规则表执行 | 提议、确认、共同锁定与过期请求有明确边界 |

这些选择构成首版可测试规则版本。不同胜负模式可以存在，但同一局只采用一个固定解释；后续规则变更必须更新版本和测试，不能修改正在进行的对局。
