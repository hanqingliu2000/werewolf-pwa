# 02 规则与待决事项

更新：2026-10-06。状态：规则工作草案。

本文件中的“基线原则”来自产品目标与重构评估；“候选默认值”是开发讨论起点，尚未通过完整对局验证。不得把旧代码行为当成规则答案。涉及待决项的实现，应先确定对应规则包的选择。

## 基线原则

- 每局固定人数、角色配比、规则版本与公开信息政策，游戏中不悄悄修改。
- 发牌随机；角色总数与实际人数一致；不默默截断或补足错误配置。
- 预言家查验默认只表达阵营，不能额外返回具体职业。
- 常规夜晚动作只允许存活的合法角色提交。猎人死亡反应是明确、一次性的例外。
- 同一批死亡先完整结算，再完成合法死亡反应，最后判胜，不能用中间态决定赢家。
- 非支持的角色重复或规则组合在开局前拒绝，不在游戏中临时降级。

## 六角色范围

| 角色 | 能力 | 必须明确的边界 |
| --- | --- | --- |
| 狼人 | 共同选择夜晚击杀目标 | 队友可见性、共同确认、空刀、自刀、分歧与超时 |
| 预言家 | 每夜查验一个合法目标的阵营 | 是否允许重复查验；提交后如何保留私密记录 |
| 女巫 | 在次数范围内选择救、毒或放弃 | 自救、同夜双药、解药目标、刀口可见性、资源消耗时点 |
| 守卫 | 每夜守护一个合法目标 | 是否自守、连守、空守，以及与解药叠加的效果 |
| 猎人 | 符合死因规则时开枪或放弃 | 夜晚和白天出局、被毒、复合死因、反应顺序 |
| 平民 | 参与白天讨论和投票 | 夜晚无真实行动，不显示会暴露他人身份的等待信息 |

## 候选规则包

建议先验证八人基础板子：2 狼人、1 预言家、1 女巫、4 平民。它是实测候选，不是已证明平衡的推荐配置。守卫和猎人通过后续候选板子验证，六角色需求范围不因此改变。

建议首版每种神职最多一人。自定义多神职的行动完成条件与结算规则未确定前，不开放重复数量。

| 项目 | 候选默认值 | 状态 |
| --- | --- | --- |
| 好人胜 | 狼人全部出局 | 候选；全员同批死亡另行确定 |
| 狼人胜 | A：存活狼人不少于存活好人 | 待确认；可考虑另一个明确的屠边规则包 |
| 守卫连守 | 不允许连续两夜守同一人 | 继承的规则候选，必须真实执行 |
| 女巫自救 | 仅首夜可自救 | 继承的规则候选 |
| 女巫药剂 | 解药和毒药各一次，同夜不可双药 | 继承的规则候选 |
| 女巫救人 | 解药仅用于本夜合法刀口 | 候选；刀口可见性另行确定 |
| 猎人反应 | 被刀或白天投票出局可开枪；纯被毒不可开枪；允许放弃 | 候选；复合死因另行确定 |
| 出局翻牌 | 对局中不自动公开身份，局后展示按确认的政策执行 | 待确认 |

如果支持 B 模式，需写明“神职全灭或平民全灭”的条件，并验证开局就没有某类别的板子是否合法。不能只用“A/B”向玩家描述胜负。

## 实施前的决策表

| 编号 | 待决问题 | 影响与完成条件 |
| --- | --- | --- |
| D01 | 首发板子、人数和胜负方式 | 选定一个规则包，说明角色配比及不支持的组合 |
| D02 | 同守同救、守卫自守和空守 | 为所有相关目标组合写出确定结果 |
| D03 | 女巫的刀口可见性、自救和空刀 | 写明药剂用尽后是否仍看刀口，以及解药何时可用 |
| D04 | 狼刀加毒药等复合死因、全员死亡 | 写出猎人是否能开枪与最终胜负，不依赖动作到达顺序 |
| D05 | 狼人分歧、行动超时和延期 | 明确等待、暂停、延期和规则允许的放弃；默认不随机代选 |
| D06 | 死亡公告、翻牌、遗言与猎人公开时点 | 同时检查玩法和信息泄露，不让私密反应提前暴露死者身份 |
| D07 | 白天误录、反应放弃和不可恢复的误操作 | 明确更正边界；新的私密信息已产生后不无痕回滚 |
| D08 | 局后翻牌与复盘数据保留时长 | 明确哪些信息公开、何时删除，重开不会混入上一局的秘密信息 |
| D09 | 身份恢复、房主和公共设备接管 | 明确失去原设备时的恢复方式、接管条件与暂停边界，房主不获得他人私密凭据 |
| D10 | 每个行动的合法目标和修改窗口 | 明确自守、自救、自刀、队友目标、重复查验、空目标及确认后能否修改 |

决策落定后应在这里记录选项、理由、适用板子和验证场景，再形成可测试的规则版本。不同变体可以存在，但同一局只能采用一个确定的解释。
