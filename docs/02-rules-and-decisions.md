# 02 规则与待决事项

更新：2026-10-06。状态：规则工作草案。

本文件中的“基线原则”来自产品目标与重构评估；“候选默认值”是开发讨论起点。表中“本轮已明确”的选项来自用户对规则的选择，仍需与首发板子一起验证；其他边界继续保持待决。不得把旧代码行为当成规则答案。涉及待决项的实现，应先确定对应规则包的选择。

## 基线原则

- 每局固定人数、角色配比、规则版本与公开信息政策，游戏中不悄悄修改。
- 发牌随机；角色总数与实际人数一致；不默默截断或补足错误配置。
- 预言家查验默认只表达阵营，不能额外返回具体职业。
- 常规夜晚动作只允许存活的合法角色提交。猎人死亡反应是明确、一次性的例外。
- 同一批死亡先完整结算，再完成合法死亡反应，最后判胜，不能用中间态决定赢家。
- 非支持的角色重复或规则组合在开局前拒绝，不在游戏中临时降级。

## 六角色范围

| 角色 | 能力 | 必须明确的边界 |
| --- | --- | --- |
| 狼人 | 共同选择夜晚击杀目标 | 队友可见性、共同确认、空刀、自刀、分歧与超时 |
| 预言家 | 每夜查验一个合法目标的阵营 | 是否允许重复查验；提交后如何保留私密记录 |
| 女巫 | 在次数范围内选择救、毒或放弃 | 自救、同夜双药、解药目标、刀口可见性、资源消耗时点 |
| 守卫 | 每夜守护一个合法目标 | 是否自守、连守、空守，以及与解药叠加的效果 |
| 猎人 | 符合死因规则时开枪或放弃 | 夜晚和白天出局、被毒、复合死因、反应顺序 |
| 平民 | 参与白天讨论和投票 | 夜晚无真实行动，不显示会暴露他人身份的等待信息 |

## 候选规则包

建议先验证八人基础板子：2 狼人、1 预言家、1 女巫、4 平民。它是实测候选，不是已证明平衡的推荐配置。守卫和猎人通过后续候选板子验证，六角色需求范围不因此改变。

建议首版每种神职最多一人。自定义多神职的行动完成条件与结算规则未确定前，不开放重复数量。

| 项目 | 候选默认值 | 状态 |
| --- | --- | --- |
| 好人胜 | 狼人全部出局 | 候选；全员同批死亡另行确定 |
| 狼人胜：人数规则 | 存活狼人不少于存活好人 | 原有候选，是否作为首发选项待确认 |
| 狼人胜：屠边规则 | 仍有狼人存活，且平民全部出局或神职全部出局 | 按用户建议新增候选胜负方式 |
| 守卫自守与空守 | 可以守护自己，也可以不守任何人 | 本轮已明确 |
| 守卫连守 | 不允许连续两夜守同一人，包括自己 | 本轮已明确 |
| 守救叠加 | 狼刀目标同时被守护和使用解药，不因同守同救而死亡 | 本轮已明确；不采用守救互相抵消 |
| 女巫自救 | 仅第一夜被狼人选为击杀目标时可使用解药救自己；第二夜起不可自救 | 本轮已明确 |
| 女巫药剂次数 | 解药和毒药各一次 | 原有候选 |
| 女巫同夜用药 | 同一夜最多使用一瓶药，也可以不使用 | 本轮已明确；不允许双药 |
| 女巫救人 | 解药仅用于本夜合法刀口 | 候选；空刀时无解药目标 |
| 女巫刀口可见性 | 本夜女巫行动窗口开始时仍有解药，才可获知本夜狼刀目标；解药用掉后的夜晚不再提供新刀口 | 本轮已明确；刀口不是最终死亡名单 |
| 猎人反应 | 被狼人击杀或白天投票出局可开枪；本次出局只要受到毒药作用，无论是否同时符合其他可开枪死因，都不能开枪 | 本轮已明确；毒药禁枪优先，包含同夜狼刀加毒药 |
| 猎人放弃 | 有开枪资格时可放弃，本次反应结束后不可补枪 | 原有候选 |
| 出局翻牌 | 对局中出局不自动公开身份；局后展示另行确定 | 本轮已明确；主动发动技能的公开方式仍待决 |

两种狼人胜利方式按独立的开局选项整理，不默认叠加。选择屠边时，狼人和好人人数相等本身不判胜；“人数规则”也不等于“杀光全部好人”的屠城规则。首发开放哪些选项由 D01 确定，不能只用“A/B”向玩家描述胜负。

本项目六角色范围中的神职为预言家、女巫、守卫和猎人；药剂耗尽不会把女巫变成平民。屠边的候选板子应同时包含狼人、平民和神职，缺失类别的自定义板子暂不列为支持候选，避免开局就被误判屠边。全员同批死亡、最后神职的猎人反应与最后狼人死亡的胜负冲突仍需按 D04 确定。

## 已选规则的边界与例子

- 女巫自救仅限本局第一夜，不是“自己第一次被刀的夜晚”。第二夜起即使还有解药，也不能救自己。
- 女巫看到的是狼人选择的击杀目标，不是最终死亡玩家；目标可能被守护或被解药救下。公开死亡名单仍在黎明按公告政策发布。
- 守卫守 A、下一夜空守、再下一夜守 A 合法；连续两夜守 A 不合法。空守不是守护某人，可以连续选择空守。
- 同守同救不会使狼刀重新生效，但不代表守护或解药可以抵挡毒药；毒药与防护的边界仍需补充确认。
- 猎人仅被狼刀击杀或被白天投票出局时有开枪资格；仅被毒、同夜被刀且被毒，都没有开枪资格。不能只保留一个“主要死因”而丢掉毒药造成的禁枪效果。
- 出局公告只公开座位和出局状态，不自动展示职业或死因。猎人主动开枪是否同时亮明身份，是另一项规则，不能在死亡公告时提前公开。

## 与常见玩法的区别

本项目不宣称采用唯一标准规则。公开规则中女巫自救存在全程禁止、仅首夜允许和全程允许等变体；本轮选择仅首夜允许。参见 [女巫自救规则](https://www.langrensha.net/strategy/2022121302.html)。

守救不冲突是需要开局显著说明的区别：常见国内规则有“同守同救导致拯救失败”的设定，本项目明确不采用。参见 [守卫规则详解](https://www.langrensha.net/strategy/2022062701.html)。这是降低反直觉情况的产品取舍，其对胜率的影响需要实测。

屠边和同刀同毒不能开枪都有公开规则先例，分别参见 [屠边说明](https://www.langrensha.net/strategy/2022022201.html) 和 [猎人同刀同毒说明](https://www.langrensha.net/strategy/2022050601.html)。这些参考不代替本项目对结算顺序和信息公开的明确约定。
