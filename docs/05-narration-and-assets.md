# 05 播报与素材

更新：2026-10-06。状态：素材需求与候选材料清单。

## 播报职责

公共播报给整桌人听，仅房主的玩家手机发声，不支持额外公共设备。私人查验、女巫刀口、未公开身份和队友提议只通过合法私密视角呈现，不生成公共音频或角色专属提示音。猎人出局公告是允许公开身份的明确例外。

文案、声音和行动窗口应来自同一个确认的规则版本。先写完整的一局脚本，再生成音频；已有音频不是让新流程沿用旧阶段的理由。

## 首版脚本范围

| 场景 | 必需内容 | 公开边界 |
| --- | --- | --- |
| 准备与试音 | 就位、声音确认、开始夜晚 | 不读出玩家身份 |
| 夜晚角色窗口 | 开眼、行动、收束、闭眼 | 死亡角色仍按公开流程呼叫；不点名谁未行动 |
| 黎明 | 天亮、无人出局或座位号死亡名单 | 普通角色不读出职业或死因；猎人在正式出局公告时公开身份 |
| 死亡反应 | 猎人身份公告、合法开枪选择、结束或放弃 | 中毒或放弃仍公开猎人身份；不能提前播报角色或直接公布毒杀死因 |
| 白天 | 讨论阶段、结果确认、进入下一夜 | 不代替玩家讨论或投票决定 |
| 结束 | 获胜阵营、平局或中止，以及可公开原因 | 判胜前不泄露全员身份；局后复盘限本局参与者 |
| 异常恢复 | 暂停、恢复、当前有效指令 | 不播报某个秘密角色或行动者异常 |

建议用座位号播报死亡，减少动态昵称合成与发音歧义。座位数字、多人死亡句式和放弃反应提示尚需补充。

## 声音与文案风格

首版采用清晰克制、简短的中文男声主持，美术与语音全部重新制作。沉浸感主要由新插画、场景和轻量转场表达，不能让诗意台词或故作恐怖的音效遮住操作含义。

实施音源采用本地 `Qwen3-TTS-12Hz-0.6B-CustomVoice` 的中文男声 `Uncle_Fu`，先验证样音，再生成静态文件；不克隆真人，也不在网页或服务器实时运行 TTS。许可和音源信息见 [官方模型说明](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice)。环境或音质不合格时记录阻碍，不静默换为付费服务。

建议同一声音与语速，统一采样格式和音量，消除爆音、过长静音与截断。音量需要在实际手机扬声器和可选外接音箱上验收，而不是只看文件存在。

公共声音失败后提供文字指令与主动恢复入口。用户选择文字主持模式后无需继续处理语音错误。未选定模式的突发音频失败应进入可恢复的公共暂停，而不是静默跳过必要指令。

## 素材优先级

| 优先级 | 需要准备 | 验收重点 |
| --- | --- | --- |
| P0 | 角色能力、规则摘要、行动与恢复文案 | 明确公开或私密语境，规则正确，术语一致 |
| P0 | 完整主持脚本与对应音频 | 覆盖开闭眼、公告、反应、结束和异常；没有秘密信息 |
| P0 | 全新六角色插画、统一身份牌背及小图 | 暗黑奇幻统一画风，小尺寸可辨认；文字独立排版，私密角色图不进入待机背景 |
| P0 | 新品牌图标、公共场景及状态图标 | 手机可读，低亮待机，不用角色颜色暴露身份 |
| P2 | 可选环境音与轻量转场素材 | 不遮住主持声音，不作为玩法必需条件 |

私人提交不发声或震动。环境音是否用于掩护操作声音，应在现场实测后决定。

## 材料管理

每份正式素材应记录用途、公开或私密语境、版本、来源、授权与验收状态。文件名不等于最终内容契约，同一版本的文案和音频应可对应。旧 TTS 生成脚本、环境参数与 UI 实现只保存在归档历史里。
