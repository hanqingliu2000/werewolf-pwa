# 27 狼人多数投票与可选试音

更新：2026-10-10。狼人新行动窗口为30秒，决策改为最多票，最高票平票随机；狼人私密面板提供历次刀口目标。房主点击语音即可准备并启用主持，试音是独立可选操作。

## 决策规则

每名存活狼人各自选择一个存活目标或空刀，再确认本人的一票，不要求其他狼人同目标。全部存活狼人投完后取最高票；2–1–1也取2票目标。并列最高时，仅在并列候选中用服务器随机源选择，空刀同样参与计票。选择与确认均不能由房主代做。

改变目标仅撤销本人的确认，其他人的票保留。沿用私密投票版本检查，过期请求必须同步后重确认。已锁定目标与请求回执一起保存，刷新、重试或重复请求不会重新抽签。

提前投完仍等待30秒窗口结束；30秒未投完保留票并自动等待，全部确认后闭窗。安全暂停、主持失联与音频不可用的保护不变。不重设旧局已经打开的窗口；30秒在新狼人窗口生效。

## 私密历史

活狼人通过历史图标查看已完成夜晚的刀口或空刀；完成投票后的身份面板也显示记录。目标来自已有夜晚日志，不重算、不新建数据库结构。被守护或解药救下的目标仍列为刀口，不宣称成功死亡，不公开额外死因。普通玩家、房主公共视图和已出局狼人的响应没有该字段。

## 可选试音

“语音”直接在点击时恢复AudioContext，校验完整音频库并上报真实播放器状态，然后启用语音；不播放sample，不要求听清确认。“试音（可选）”只在用户选择后播放sample，不是准入条件；文字模式试音也不自行切成语音。刷新或中断后可以直接恢复声音，无需先试听。

保留音频资源、SHA/字节/时长校验、播放结束回执、旧音频版本安全暂停及主持前台心跳。声音被浏览器阻止或素材失效时不能伪装成功，仍可明确切回文字。旧客户端的trialConfirmed字段继续接受，但不再参与启用判定。仍使用40段host-zh-v3；现有狼人播报要求全体确认，与各自确认一票相容，不包含一致投票或15秒要求。
