# 守救规则 语音倍速与大厅移出

2026-10-12，按用户确认修改四项行为，验证后发布到现有正式站。仅开局前移出玩家，不改变中途阵营人数；不增加认证或收费资源。

## 行为

- 狼刀目标只被守护或只被解药救治时免狼刀；同时被守护和救治时死亡，按狼刀死因记录。毒药禁枪优先规则不变，未中毒的猎人因此死亡仍有反应机会。
- 新开的守卫、女巫、预言家和猎人窗口为10秒；狼人仍为30秒。已打开的窗口不被部署强行重置。死亡或耗尽角色仍完整播报并保留对应固定窗口；超时只等待，不自动放弃。
- 播报默认1.5倍，主持面板及公开语音状态旁提供2倍按钮，再次点击恢复1.5倍。只改变播放器速度，不改变服务器行动时长；真实播放结束回执之后才开行动窗口，不依据估计时长提前推进。
- 速度是本页播放器设置，刷新恢复默认1.5倍；音频素材及指纹未改。使用原生Web Audio playbackRate，速度变化也会影响音高，本轮未实现保调时间伸缩，未宣称真机音色已验收。
- 房主在大厅点击席位旁“管理玩家”，在完整名单中确认移出他人；原“主持控制 → 席位维护”入口保留。普通玩家没有移出按钮，房主不能移出自己，发牌后服务端拒绝移出。移出不等于永久封禁，仍可在大厅重新加入；不影响此前合法参与的复盘授权。

## 验证

287项规则、服务和保存测试通过，类型检查、lint、生产构建通过。覆盖单守、单救、双守救死亡、毒药优先及双守救猎人反应；播放器验证默认1.5倍、切换2倍时当前与下一片段生效，仍只由真实ended完成。

Chromium和WebKit验证默认1.5倍及2倍实际source速率、可选试音、10秒守卫、声音阻止/中断/刷新/明确恢复/文字回退，以及管理入口、移出确认和被移出会话失去读取权限。各平台同时保留前台自动行动和超时静默等待回归。首次运行的恢复断言仍在已加载脚本中使用旧30秒扩展，更新为10秒后最终构建重新运行通过；未改变服务的安全暂停规则。

临时评审样例同步为10秒守卫，6项隔离测试通过。原始测试数据库、截图、日志和私密配置不提交仓库。正式发布的提交、部署、线上复查与测试房间清理记录在发布后补充。

本轮没有重新跑完整语音局或真实手机现场音频。此前整局记录对应旧规则，不能视为守救新规则及倍速整局已验收。
