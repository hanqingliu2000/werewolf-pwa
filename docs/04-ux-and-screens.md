# 04 UX 与页面地图

更新：2026-10-07。状态：高层体验基线，具体流程见 [12](12-web-flow-design.md)，文字网页与新视觉已实现，验收见 [14](14-web-design-and-acceptance.md)。

## 体验原则

采用同一套响应式网页，先设计手机端。玩家的当前任务占据首屏；历史、设置和维护操作位于次级入口。公共声音服务于全桌，私密屏幕服务于本人。

视觉方向已选定为暗黑奇幻沉浸风：全新六角色插画、统一牌背与场景位图，配合清楚的座位和行动排版。采用炭黑基底、暗红与冷绿辅助色，动效克制；夜晚低亮，白天易读。待机视觉统一，不因角色改变背景、颜色或亮度；旧深蓝配色和卡片布局不是约束。

## 页面地图

| 页面或状态 | 主任务与主要内容 | 关键补充状态 |
| --- | --- | --- |
| 入口 | 创建、加入、恢复当前对局 | 房间失效、已有身份、链接自带房间信息 |
| 建房 | 选人数与推荐板子，确认公开规则 | 不合法配比、进阶设置、提交中 |
| 大厅 | 座位、昵称、准备、邀请二维码和规则摘要 | 满员、退出、误入座位、重新连接 |
| 身份查看 | 按需揭示本人身份与能力，不要求确认或记录查看进度 | 统一牌背、收起、隐私遮蔽 |
| 玩家夜晚 | 当前合法行动、座位目标、放弃或确认、提交回执 | 无可用资源、等待、请求中、失败重试 |
| 狼人协作 | 私密队友名单、各自提议、共同目标与确认 | 分歧、未选齐、队友断线 |
| 公共主持 | 当前公开指令、窗口状态、声音状态 | 试音、暂停、播放受阻、恢复、文字主持 |
| 白天 | 公共死亡与座位状态，线下讨论，房主录入结果 | 草案、确认待发布、发布前更正、待处理反应；不内置发言计时 |
| 死亡反应 | 公开猎人身份，合法猎人本人选择目标或放弃 | 被毒无开枪入口、已放弃、已完成；不得提前揭示身份 |
| 结束 | 胜负、全部身份和逐夜复盘，下一局 | 中止、玩家变动、规则重新选择、参与者权限 |

这些是体验状态，不是要求逐一新增 URL。路由与组件划分在后续技术设计中决定。

## 夜晚行动布局

- 首屏先出现当前行动及目标选择，播报设置不能排在玩家行动之前。
- 目标按固定座位顺序排列，显示座位号和昵称；姓名过长时换行而不挤压按钮。
- 选择只表示草案，正式确认后锁定并显示已接受回执。狼人的个人提议可修改，变更会清除共同确认，最终全体一致才锁定行动。
- 身份与私密记录默认遮蔽，查看后可快速收起；离开页面或对局恢复时重新遮蔽。
- 待机页统一，不展示身份、行动者姓名或角色数量变化来解释等待。
- 查验、药剂等私密记录放在本人次级入口，不常驻于公共展示区域。

## 房主与公共控制

房主维护入口与本人玩家行动分开，房主的同一手机承担公共播音，不提供额外设备或接管入口。播音不影响本人秘密操作，公共内容不包含私人身份。投票录入显示座位号、昵称，依次选择、确认待发布和发布；草案可改，发布后不可撤销，空白选择不能误解释为无人出局。

超时暂停或声音失败给出恢复当前窗口和主动切换文字主持的入口。刷新仍在原浏览器恢复；不展示换设备恢复码或主持人接管按钮。猎人无论中毒或放弃都保留公开身份，但没有资格时不能显示可点击的开枪动作。

播放器状态和游戏操作反馈分开呈现。音频错误不能覆盖目标选择、吞掉下一次点击，或要求所有玩家重新点击解锁声音。

## 触控与可访问性

- 主要触控目标至少 44px，邻近操作保留间距。
- 颜色不是区分选中、失败、死亡与禁用的唯一方式。
- 长昵称、大字体、窄屏和浏览器底部工具栏下仍能完成主要操作。
- 所有重要播报有等价的公开文字；私密信息不进入公共朗读或通知。
- 操作反馈明确，错误贴近相关操作；等待不伪装成一直加载。

## 首轮原型应验证

新玩家能否找到当前任务，座位与本人是否对应准确，狼人能否无需额外聊天系统就达成目标，房主兼玩家时能否完成自己的行动，以及一次刷新或音频失败后是否知道怎么继续。
