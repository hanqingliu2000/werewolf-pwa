# 15 主持语音与播放器验收

更新：2026-10-07。本轮交付阶段 4 剩余的公开脚本、新中文男声资源与播放器，沿用已经完成的美术和网页。当前为本机候选版本；没有创建新云端后端、部署或替换原网址。

本页保留首批 V1 的验收记录。用户随后选定 B 平直播报，当前已切换 V2；最新声音、升级保护和测试见 [16](16-neutral-narration-acceptance.md)。

## 交付范围

- `web/src/narration/script.json`：`host-zh-v1` 对应 `werewolf-web-v1`，28 段公共短句与 12 段座位号。
- `web/public/audio/host-zh-v1/`：40 个新 MP3，合计 223.52 秒、2,722,208 字节。24kHz 单声道、96kbps；文件清单包含台词、SHA-256、模型 revision、种子、参数与来源许可。
- `scripts/`：固定依赖的本地生成与 ASR 复核工具；环境、模型和原始录音不进入 Git。
- `src/narration/plan.ts`：只接受公共投影，组合开闭眼、公告、投票、猎人、结束与新大厅指令。
- `src/narration/player.ts` 与网页控制：真实试音、试听确认、音量、顺序播放、故障暂停、重试和明确文本回退。
- 服务端：持久保存待播公告，检查公告编号与窗口，防止旧结束回调推进新的阶段；旧房间默认文字模式，无需清库。

声音沿用已选 [Qwen CustomVoice](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice) 的 `Uncle_Fu`。本机采用同源 MLX 4-bit 转换，模型 revision 为 `08c72cad5e2fd0f41730c8bd1f28149585e46361`。没有真人克隆、付费接口、旧音频复制或网页实时 TTS。完整生成方法见 [scripts](../scripts/README.md)。

## 流程与信息边界

大厅选语音后先加载、核验并解码完整银行，播放实际样音，只有播放结束且房主明确确认听清才启用语音。浏览器刷新或中断后不假定仍有播放许可。服务器信任原房主的确认与客户端播放回执，不能独立证明用户硬件实际发声。

开眼指令序列的最后一个真实 ended 事件才发送固定上下文的 `cue_ack`，服务端随后设置 30 秒或 45 秒截止时间。提前行动不改变闭窗时间。关闭主持面板、打开本人身份或提交个人行动都不重启公共序列。

黎明先播天亮提示，再发布死亡事实；名单只从已经公开的事件组合，按座位号播报。猎人身份随合法出局公告公开，但不播报毒药、刀口或其他死因。私密查验、药剂、队友提议、未公开身份和缺少行动者永不进入声音计划。

语音公告未完时，界面显示公共公告，服务端禁止开始下一夜、推进指令、发布下一投票、开枪或重开。猎人任务在公告完成后才开放。中止会替换当前未完成公告，重开使用新大厅与新公告，不能重放旧局队列。

音频拒绝、资源缺失或篡改、AudioContext 中断、播放超时、失去主持页或后台都停止当前序列；活跃对局进入暂停。恢复只处理当前有效指令，不能重复结算。文字回退是明确选择，未完成公告仍需手动读完确认。

页面离开与故障状态使用同源 JSON Beacon，并保留小型 keepalive 后备；房主每 3 秒心跳、失联 10 秒暂停仍是服务端兜底。Beacon 已排队不代表已送达，前台心跳也不会自动恢复对局。[浏览器生命周期说明](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/sendBeacon)

## 本机验证

| 检查 | 本轮结果 |
| --- | --- |
| 类型与代码检查 | 通过 |
| 单元、规则、属性、权限与信号清单测试 | 197 项通过；包括完整 8 人、12 人语音公告契约对局与重开 |
| 覆盖率 | 语句 97.46%，分支 94.21%，函数 97.08%，行 98.87%；未降低原门槛 |
| 生产构建与 HTTP smoke | 通过；独立会话、最后席位竞争、权限、重复请求及真实服务重启 |
| Chromium 和 WebKit | 14 项回归通过；报告为 `web/test-results/browser-report.json` |
| 信号与本地 ASR | 40 段指纹匹配，无削波；解码样本最大峰值约 -1.72dB；重做了明显异常片段 |

浏览器用例覆盖全部文件的真实解码与校验、真实样音和 ended、自动播放拒绝、缺失与篡改、音量、面板关闭、暂停、刷新、重新试音、后台、文本回退、旧轮询竞态，以及既有 8 人和 12 人文字页面对局。声音控制在 360、390、768、1440px 截图检查中保持 44px 触控目标和无横向溢出。

本轮修复了原生 fetch 的调用上下文、操作保存后复用旧轮询、主持面板与窗口配对、退出时 WebKit 请求取消，以及模式按钮没有套用既有触控样式的问题。异常恢复仍通过正式接口，不增加生产测试后门。

ASR 不等于人耳验收。采用本地 MLX Whisper small 复核，报告与原始 WAV 只在受限、被忽略的 `.local-generation/` 保留；存在同音字、繁简转换与短句识别误差，不能据此保证所有发音自然。`manifest.json` 明确保留 `humanPhoneListening: pending`。

用户随后试听并反馈部分首批声音演绎过强，要求降低 dramatic 程度。因此40段仍为候选，不是音质定稿。新方向是平静、自然、简短，不靠主持声音渲染恐怖感；先对比风格小样，再替换全套。实验性小样独立于 `host-zh-v1`，不进入游戏自动播放队列，也不改规则、接口和播放器验收结论。
