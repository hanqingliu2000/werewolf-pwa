# 11 本地保存与权限验收

更新：2026-10-06。本记录保留阶段 2 当时的验收快照；随后文字网页已实现并验收，见 [14](14-web-design-and-acceptance.md)。

本轮在唯一规则核心之外增加房间协调、SQLite 保存、原浏览器会话和真实 HTTP 接口。没有恢复旧数据库结构，没有连接云端，也没有提交、推送或部署。

## 交付范围

| 能力 | 实现 |
| --- | --- |
| 房间事实 | 文件数据库保存大厅、成员、当前局、资源、窗口、事件和局后档案；模块内存不作为事实来源 |
| 原子写入 | 内部版本比较加有界重试；成功状态和请求回执在同一事务提交，失败不覆盖较新事实 |
| 原浏览器身份 | 256 位随机会话凭据放在 HttpOnly、SameSite Strict、主机专属 Cookie；HTTPS 下加 Secure；数据库仅保存摘要 |
| 大厅 | 建房、加入、准备、空座位选择、改名、修改配置、移除成员和开局；开始前人数与准备状态必须满足配置 |
| 信息投影 | 公共视图、本人私密视图、房主组织视图和参与者复盘分开；没有完整权威状态读取接口 |
| 公开时点 | 夜间内部死亡不能提前改变公开名单或本人显示的存活状态；猎人只在死亡公告中公开身份 |
| 请求语义 | 请求编号去重、当前局和窗口校验；狼队确认额外绑定提议版本，白天确认及发布绑定草案版本 |
| 协调与恢复 | 服务端时钟控制固定窗口；心跳失联、后台或声音状态异常暂停，恢复必须由原房主明确发起 |
| 数据期限 | 实际改变事实的操作续期 24 小时；轮询、心跳、重复回执和无变化请求不续期；档案有独立截止时间 |
| 防护 | 同源写请求、严格输入、16 KiB 请求体上限、持久化频率限制、私密响应禁止缓存；异常不回显原始数据 |

只有文字主持协议已接入：房主确认当前公开指令后开放行动窗口或发布公告。音频试音、资源与实际播放器仍属于阶段 4；`audioReady` 是未来播放器上报状态，不代表服务器验证了扬声器发声。

## 已执行验收

- `npm run check`：类型检查、ESLint、全部测试和覆盖率门槛通过。
- 169 项自动化测试通过，原规则测试及 500 次固定种子生成检查保留。新增测试覆盖存储事务、会话权限、接口防护、协调与 8 人及 12 人完整持久化对局。
- 两个 SQLite 连接的条件写入检查通过：旧快照不能覆盖新状态，状态和回执共同提交，回执失败回滚。
- 建房重试、加入重试、行动重试、重复开局和退出重试不产生重复效果；不同内容复用请求编号被拒绝。
- 房主不能读取其他身份或未公告夜间行动；普通玩家不能冒充房主、使用他人 `actorId`、跨房间读数据或读取未参加的复盘。
- 提前完成不会提前关闭窗口；缺少动作不自动放弃；失联暂停保留剩余时间，恢复在保留时间上增加 30 秒。
- 中止和新一局清空当前角色状态、药剂、查验、连守限制与共同确认；旧参与者档案权限不扩散给新加入者。
- `npm run build`：生产构建通过，没有动态文件追踪警告；运行时数据库不是部署资源。
- `npm run smoke`：真实生产 HTTP 服务验证独立会话、并发争最后席位、私密身份、重复开局，并真正停止和重新启动服务验证同一身份与对局恢复。临时服务和测试数据库自动清理。

阶段 2 当时尚无完整页面。后续浏览器与手机尺寸结果见14；这些结果仍不等于真机自动播放或扬声器验收。

覆盖统计包含规则核心、服务模块和健康入口，排除纯类型定义；薄路由装配通过生产 HTTP 测试验证。门槛未降低：语句 98.12%、分支 94.95%、函数 98.88%、行 98.65%。

## 实施边界

SQLite 只供本地验证，不能作为 Vercel 多实例的正式持久化。当前存储端口同步调用 SQLite；未来云端适配必须实现等价的条件更新和回执原子提交，并处理异步事务，不能直接套用文件数据库或复制规则到数据库函数。接口契约见 [13](13-room-service-contract.md)。

到期检查和物理删除在服务请求时惰性执行，过期后始终拒绝访问；没有常驻清理任务。无请求时过期文件中的行可能保留到下一次访问，线上需要增加定时清理。SQLite 的实验性 API 标记仍存在，继续锁定 Node.js 24.14.1。[Node.js SQLite 文档](https://nodejs.org/download/release/v24.14.1/docs/api/sqlite.html)

频率限制包含全局和会话限额，尚未集成受信任代理的来源地址限额、云端访问控制或互联网攻击负载测试。Cookie 防护不能防止同源脚本漏洞，正式页面需要继续避免脚本注入并配置内容安全策略。[MDN Cookie 属性](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie)
