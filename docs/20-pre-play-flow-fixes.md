# 20 试玩前流程检查与修复

更新：2026-10-08。范围：行动面板、语音完成回执和白天录入防误发布。遗言由人工主持安排，不增加线上阶段，不改变猎人反应、判胜和下一夜的规则顺序。

## 行动面板

- 行动期间缩小本人插画和身份摘要，完整角色规则折叠在次级区域；发牌确认及普通待机仍保留完整身份展示。
- 目标按固定座位排列，行动面板使用紧凑三列；长昵称完整换行，不依赖缩小字号或省略座位。
- 顶部倒计时、底部选择摘要及确认操作不随目标列表滚动。两者独立于滚动区，预留安全区，保留关闭与键盘操作。
- 女巫确认前显示所选药剂与目标；不守、不查验、空刀和放弃开枪仍是需要主动选择的选项。
- 主屏和私密面板使用同一个倒计时组件，只展示服务端时间。守卫30秒、狼人15秒、女巫/预言家/猎人10秒不变。
- 狼人自动等待时显示私密的协商等待状态，仍允许提议和共同确认；不增加手动暂停按钮。

## 播报确认恢复

语音实际播放完成后，保存原请求编号、对局编号、窗口编号和完成操作。推进请求被拒绝时，主页面及主持面板提供“重试播报确认”，只重发同一完成回执，不重播已完成音频，也不生成新请求编号。

网络结果未知时仍使用现有“重试原请求”。重试期间防止重复发送；进入另一局或另一窗口、切换主持方式、失去主持页资格或音频失效后，旧回执不能作为当前阶段的推进依据。音频真正中断仍走原暂停与试音恢复路径。

## 白天结果

读取已保存草案时，选中状态和核对摘要保持一致。改选其他玩家或无人出局但尚未保存时，明确标记“改选未保存”，禁止确认和发布旧草案。重新保存会撤销服务端旧确认，必须再次核对才能发布。

最终发布确认绑定具体草案编号，而不是只保存一个布尔状态。另一标签页更新草案后，旧发布确认不转移到新结果；房主须重新打开发布确认。服务端已有草案版本检查及发布前后权限边界不变。
