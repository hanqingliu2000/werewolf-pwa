# 18 行动计时与死亡角色播报验收

更新：2026-10-07。音频仍为 `host-zh-v2`，本轮不重新生成素材、不改动云端数据。

## 当前行为

- 守卫30秒；狼人15秒；女巫、预言家10秒。均从睁眼播报真正结束后开始。
- 狼人提前共同确认仍保留完整15秒窗口；到时未全体确认则自动等待，私密提议和共同确认仍可继续。全体存活狼人一致确认后自动进入闭眼播报。不提供狼人手动暂停按钮或命令。
- 狼人自动等待不同于安全暂停。房主不可用、切后台或播报故障仍会阻止行动，需要明确恢复。
- 已配置的死亡神职和药剂耗尽的女巫仍保留开闭眼播报及与存活角色相同的窗口；不要求死亡玩家提交行动。
- 猎人公告播完后才开始10秒反应时间；超时安全暂停，不自动放弃开枪。
- 安全恢复保留剩余时间，并追加本角色的正常操作时长。
- 后续按用户要求加入前台行动面板自动打开：以服务器本人可行动状态为准，同一逻辑行动只打开一次，关闭后不反复弹出，切后台立即隐藏；手动入口保留。死亡神职及资源耗尽的女巫不弹出，猎人须等待公告结束。

## 自动化检查

`npm run check`：15个测试文件、212项通过；语句覆盖97.47%、分支94.23%、函数97.1%、行98.91%。生产构建通过。

新增回归覆盖死亡守卫、女巫、预言家的完整开闭眼计划及等长窗口，存活女巫和预言家10秒、猎人公告后计时和不自动放弃、狼人15秒提前确认及超时等待、部分确认保留、非狼人和死亡狼人拒绝操作，以及房主不可用覆盖协商等待。

其中公告计划与服务回执测试不是实际播放测试；真实音频播放另由多人浏览器验收覆盖。

## 浏览器验收

可见 Chromium 的12人真实语音局通过，耗时约9.6分钟。每名玩家使用独立浏览器会话；首夜击杀预言家，第二至第五夜实际保留其10秒窗口并播放开闭眼音频。首夜狼人实际等待15秒进入自动等待，再经私密页面共同确认。未替换 MP3、加速声音或伪造 ended 回调。其他已提交行动的等待窗口仅在隔离测试数据库中压缩。

已检查自动等待私密界面和第二夜死亡预言家的10秒公共窗口截图。整局还通过猎人被投票出局后主动放弃开枪、五夜投票清狼、好人获胜、复盘、重新试音及新大厅公告。浏览器用例为 `12 isolated players complete a real voice UI game and a new lobby`，没有过滤页面错误。

实机外放、蓝牙、来电、锁屏和聚会节奏仍待验收。本轮没有重新执行 WebKit 完整语音局，历史结果见 [17](17-voice-game-acceptance.md)。

## 前台自动打开补充验收

新增 `auto-action.spec.ts` 在 Chromium 与 WebKit 均通过。该用例使用受控接口响应，检查守卫、预言家、有药女巫、等待协商的狼人及公告后的猎人自动打开；主动关闭、同轮暂停恢复和后台隐藏后不重弹；后台新行动不打开，返回前台后可打开；死亡角色、无药女巫及猎人公告期间不打开。此用例验证浏览器交互，不代表真实多人或真实手机验收。

另补跑 Chromium 的8人真实文字网页整局，行动、阶段切换、猎人反应、投票、复盘和新大厅均通过，并检查私密预言家窗口截图。已有多人验收辅助步骤改为接受自动打开的面板，未取消行动和结果断言。最终 `npm run check` 的212项测试、类型检查和 lint 通过，生产构建通过。本次自动打开修改后未重跑完整语音局；上方12人语音结果来自此前计时修改版本。
