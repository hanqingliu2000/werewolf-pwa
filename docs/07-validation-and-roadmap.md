# 07 验证与重构路线

更新：2026-10-07。状态：规则、保存权限与文字网页已验收，正式声音与实机验收仍未完成。

目标是验证“朋友通过网页可以稳定玩完一局”，而不是恢复旧功能清单或先完成视觉换皮。阶段、进入条件、交付物与上线顺序统一见 [09 分阶段开发计划](09-phased-development-plan.md)；本文集中记录验证范围，不另维护一套阶段顺序。

## 验收分层

| 层次 | 验证内容 | 门槛 |
| --- | --- | --- |
| 规则核心 | 配置、随机发牌、合法动作、死亡批次、猎人、胜负和中止 | 所有已选分支有确定性测试，结果不依赖动作到达顺序 |
| 接口与存储 | 权限投影、原浏览器会话、请求去重、条件更新、重启恢复 | 不越权、不丢事实、不重复消耗、不覆盖更新 |
| 浏览器体验 | 完整一局、白天草案发布、暂停、音频恢复、复盘与重开 | 真实页面可操作，跨视口无重叠，素材不是空白 |
| 云端准备 | 免费额度、新后端安全、旧数据范围、可恢复备份与清空 | 任一检查失败均阻止清空或上线 |
| 线上仿真 | 12 个独立玩家 agent 和会话，含房主，完成一局与重开检查 | 玩家不读全知数据，按正式规则行动，结果与复盘一致 |
| 真机与聚会 | iOS Safari、Android Chrome 的声音和现场操作，候选配比平衡 | 单独记录设备与观察结果，不用仿真替代 |

旧测试只作为场景来源；固定发牌、按存活角色缩短公开流程或漏掉猎人放弃都不能因旧测试通过而成为新要求。真实聚会建议先完成 3 至 5 场混合手机浏览器对局，再将经过实测的配比升级为推荐；每局仅房主手机播音，不测试不存在的额外公共设备功能。

| 场景 | 应观察的结果 |
| --- | --- |
| 首次加入、重开、席位变化 | 身份与座位准确；没有重复入座或重复发牌 |
| 狼人分歧、队友短时失联 | 有规则允许的处理方式，公共提示不泄露角色 |
| 女巫首夜自救、第二夜自救尝试、同夜双药尝试 | 仅首夜自救合法；第二夜自救和同夜双药不被接受，不错误消耗药剂 |
| 女巫有解药、用药后的下一夜、刀口被守护 | 仅有解药时获得新的本夜刀口；不把狼刀目标显示成已确定死亡 |
| 守卫自守、空守、连守、空守后再守同一人 | 自守和连续空守合法；连守被拒绝；间隔空守后再守合法 |
| 狼刀目标同守同救、受毒与防护的组合 | 同守同救不因叠加死亡；守护和解药均不能抵挡毒药 |
| 夜晚和白天猎人死亡、放弃开枪 | 无毒时狼刀和投票出局有合法反应；放弃不阻塞流程，判胜等待完整反应结束 |
| 猎人仅受毒、同夜狼刀加毒药 | 两种情况都不能开枪，不因狼刀也是死因而误开技能 |
| 屠边模式的平民全灭、神职全灭、人数相等 | 前两种按完整结算后的胜负规则处理；仅人数相等且两边未灭不判屠边胜 |
| 开局缺少平民或神职、双方同批满足胜负条件 | 配置与胜负有明确解释，不误判开局屠边，不依赖动作到达顺序 |
| 死亡公告、出局名单、猎人禁枪或放弃 | 普通角色不自动公开身份，猎人出局公开且不得提前；被毒或放弃仍公开，不直接公布死因或剩余分类人数 |
| 夜晚已经满足胜负条件 | 不额外要求白天再投一次才结束 |
| 刷新、网络中断、公共页离开前台 | 能恢复当前事实，没有重复消费资源或补播旧台词 |
| 音频受阻、声音缺失、文字主持 | 用户能理解暂停与降级，动作点击不被吞掉 |
| 房主出局或离线 | 出局保留组织权限；失联暂停等待原浏览器，不提供接管或换设备身份恢复 |
| 无人出局、平票线下处理、误录 | 草案与待发布可改，发布后不可撤销；系统不代替线下投票，严重误录可明确中止 |
| 局后与下一局 | 胜负可解释，信息按政策公开，新局与旧局隔离 |

## 体验指标与记录

记录邀请到就绪时间、整桌准备时间、正常白天录入之外的维护次数、卡住时间、误点、音频恢复次数和再次开局意愿。建议目标见 [01](01-product-requirements.md)，实际结果与设备、浏览器版本一起保存。

可以在真实游戏前用简短测试模式演练指令与恢复，但不能让演练身份或动作进入正式对局。

## 发布与后续

新美术和全套新主持语音是首版交付，不能留作未完成的换皮后续项。候选人数配比的平衡与真机声音验收另列实测记录；安装增强和环境音后续推进，原生 App 不属于这条路线。

本轮规则、保存权限、生产构建和真实 HTTP 重启检查已通过，但不是阶段5的完整多人页面验收。旧云端业务结构清理已完成，网站替换和逐玩家仿真仍未执行；验收见 [10](10-foundation-and-rule-core-acceptance.md) 与 [11](11-persistence-and-permissions-acceptance.md)。
