# 31 主持自动恢复、保音调加速与首夜竞选

日期：2026-10-13。状态：本地验收，提交推送但不部署正式站。

## 行为

- 系统中断、失联或声音不可用导致的 `host_unavailable`，在原主持前台心跳、音频版本和声音就绪后自动解除。计时只恢复冻结的剩余毫秒，不重新发放行动时间；已接受行动不清空。
- 人工 `manual` 暂停仍需房主手动恢复，保留既有恢复宽限。不因返回前台或普通点击自动继续人工暂停。
- `visibilitychange`、`pageshow` 立即同步。播放器自动恢复；必要时借普通点击解锁。恢复有超时，并检查音频时钟确实前进；卡住时重建音频上下文，复用验证过的缓冲区，不刷新整页。自动尝试有上限，恢复按钮兜底。
- 未完成播报可以重播当前有效 cue，已经服务端确认的公告不重播。网络未知结果用原请求 ID 自动重试最多三次；播报回执冲突也自动有限重试，不重播声音。过期回执不推进新阶段。
- 语音主持申请屏幕 Wake Lock，返回前台重新申请，结束或退出主持后释放。低电量、浏览器拒绝及后台限制仍可能使其失效，不承诺锁屏后台主持。

## 首夜警长竞选

最后一个夜间角色闭眼后内部结算，进入持久化的首夜竞选子阶段：

1. `hands_prompt`：请保持闭眼，竞选者举手；播报真正结束后为 `hands`。
2. 房主结束线下举手，进入 `speech_prompt`：所有人睁眼，竞选者发言、线下警长投票；播报结束后为 `speech`。
3. 房主点击竞选完成，进入 `complete`，播报现在公布昨夜结果。
4. 原有出局公告、猎人身份/反应、胜负和白天流程继续。

竞选不设倒计时、不记录候选人、选票、警长或警徽。普通白天淘汰投票在此期间不可用。所有公开存活名单、狼人队友存活标记、本人存活状态仍按已公告事件投影；夜间结果及猎人身份不提前公开。第二夜起清除子阶段，沿用原来的天亮播报。旧的已经进入黎明的存档无子阶段时继续旧流程，不追溯插入竞选。

## 狼人队友

私密身份页直接显示狼队席位、昵称、本人及已公布存活状态；行动面板通过人物图标查看，不占用目标网格高度。只有本房间狼人获得 `teammates`。已出局狼人可以回看已知队友，但不获得新的提议或行动入口；其他角色、房主组织视角和公共响应不获得狼队身份。

## 声音

- `host-zh-v5` 共48段原速素材：45段复用不可变 V4，新增三段警长竞选与结果衔接。
- 新增台词：请保持闭眼。竞选警长的玩家请举手。／所有玩家请睁眼。竞选玩家请依次发言，随后进行警长投票。／现在公布昨夜结果。
- 使用已缓存 Qwen3-TTS、Uncle_Fu 平直播报风格离线生成，不上传对局数据、不新增付费服务。信号与本地 ASR 已检查，短语同音识别仍有误差，人耳及真实手机试听待用户确认。
- 使用 FFmpeg `atempo` 生成1.5/2倍保音调素材，共96段。运行时验证完整版本、文字、指纹、字节和时长，原生 Web Audio 以 `playbackRate=1` 播放。不使用升调变速。
- 速度按钮在下一片段生效，不截断当前词句；默认1.5倍、可切2倍，行动时间仍为狼人30秒，其他行动角色10秒。
- 本地试听：http://127.0.0.1:3030/audio/host-zh-v5/index.html ，支持原速、1.5和2倍素材对照。
