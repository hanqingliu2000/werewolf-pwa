# 25 身份牌立绘比例调整

更新：2026-10-08。已按用户要求放大私密身份牌立绘，完成本机验收；本次不提升正式部署，正式版本仍见 [24](24-identity-flow-production-release.md)。

## 展示调整

- 常见手机竖屏采用立绘居中、角色名和规则在下方的布局。在375x812及390x844视口中，图片从96px宽增至216px，保持完整3:4比例。
- 桌面与平板采用立绘和说明并列，图片从150px宽增至最多300px。短竖屏保留并列布局；低高度横屏按可用高度及底部安全区约束图片，不为放大而截断主体。
- 保持原有六张WebP、文案、字体、颜色与隐私边界，不生成或重新下载素材。查看前、收起后及切到后台时均不显示角色内容。
- “收起私密信息”移至滚动区域外并固定在面板底部，规则或查验记录变长时仍可立即遮蔽；顶部关闭入口保留。
- 仅使用身份查看专属样式。行动阶段的36x48px小图、目标、计时、确认和单屏布局保持不变，不修改规则、接口、声音或数据保存。

## 本机验收

| 项目 | 结果 |
| --- | --- |
| 类型、代码、规则与服务检查 | 253项通过；覆盖率门槛不变 |
| 生产构建 | 通过 |
| 身份查看布局 | Chromium和WebKit各覆盖六角色、发牌及等待两种状态、10个视口，共240个组合通过；图片完整可见、无文字重叠、无横向溢出、关闭和收起均至少44px且在屏内 |
| 原行动布局 | 两种浏览器、8/12人、五行动角色、9个视口，共180个组合通过；所有目标、计时及操作仍一屏可见 |
| 长记录与隐私 | 两种浏览器均通过12条预言家记录滚动、底部收起位置不变、键盘收起、减少动态及后台遮蔽 |
| 截图复核 | 查看390x844女巫与1440x900预言家截图，立绘清晰放大、没有裁切或控件覆盖 |

身份查看视口为320x568、360x560、360x640、375x812、390x844、768x900、1440x900、640x320、740x360和844x390。首次320px用例发现原生dialog默认最大宽度额外压缩了面板，已通过身份面板专属宽度约束修正后复测，未降低大小或可见性断言。

浏览器布局用例使用本机模拟房间与真实图片，不是完整对局、云端发布或真机验收。截图与测试数据库不进入Git。本地预览沿用 `http://127.0.0.1:3000/`。
