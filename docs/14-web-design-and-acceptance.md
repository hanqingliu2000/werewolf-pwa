更新：2026-10-07。交付为可运行的本地文字主持网页，不是静态线框。视觉规范见 [设计基线](../design-system/werewolf-web/MASTER.md)，正式声音与云端发布仍未完成。

## 完成范围

入口、创建、加入、大厅、二维码、准备和配置维护已接真实接口。完成默认身份遮蔽、本人确认、夜间目标、狼队协作、女巫药剂、查验记录、同机主持、黎明公告、猎人反应、白天录入、复盘与下一局。

页面只消费过滤视图。私密和主持响应包含当前局与窗口编号，网页按同一上下文组合显示；角色不进入路由、标题或通知。刷新、后台、Escape 与阶段切换收起私密面板，草案不迁移。未知结果保留原请求编号与内容，在可操作面板内重试。

同浏览器主持页用短期租约与 BroadcastChannel 协调，其他页不争抢心跳。这不是硬件身份绑定或换设备恢复。房主出局保留组织控制。

## 视觉与素材

暗黑奇幻与编辑式排版采用炭黑、暗红、冷绿、宋体标题与无衬线正文。全新场景、牌背和六角色图共约 1.31 MB，本地字体附 OFL 许可。无旧素材、营销功能卡片、3D 或角色待机色。

触控至少 44px、座位号固定、长昵称完整换行。手机大厅操作吸底并预留安全区。段选、数字输入、明确放弃、确认与发布分开，弹窗使用原生 dialog。

## 验收方法

`npm run check` 执行类型、ESLint 与 175 项测试，保留原规则、权限与存储测试，新增请求初始化、错误处理和不确定响应检查。覆盖率仍统计规则核心、服务与健康入口，不是前端组件覆盖率。

`npm run build` 执行生产构建。`npm run smoke` 检查 HTML 入口、会话、并发加入、权限及真实服务重启，不接云端。

`npm run test:ui` 用独立本机生产服务和数据库，执行 Chromium、WebKit 各三项用例：入口视觉、8 人完整对局、12 人完整对局。每人独立上下文，通过真实表单与操作完成游戏；角色判断来自各人的本人视图，不给页面全知状态。[Playwright 上下文隔离](https://playwright.dev/docs/browser-contexts)

检查覆盖 360、390、768、1440px、长昵称、图片加载、键盘焦点、减少动态、后台遮蔽、玩家刷新、暂停恢复、响应丢失重试、猎人延后反应、房主出局、复盘与下一局。截图和报告在忽略的 `web/test-results/`。

快速验收仅由测试协调器在隔离数据库缩短已完成动作窗口的截止时间，并按原窗口时长推进测试限频桶。生产窗口与限额不变，浏览器没有时间注入接口。真实 30 秒与 45 秒、不能提前关闭、缺失动作暂停，由规则与协调测试单独验证。
